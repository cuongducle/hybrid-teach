# Changelog

## 0.2.0

- Default learning data to an external workspace; explain tracked-file, cloud-sync and hosted-model privacy limits.
- Checkpoint meaningful evidence during sessions and reconcile partial state on return.
- Track scope, assistance, delay, transfer and verification independently, with conservative migration of old records.
- Specify review transitions for new, successful, assisted, failed, skipped, overdue and disputed items; never reset untouched items at session close.
- Verify tasks before use, accept alternative solutions, and suspend disputed grading.
- Clarify that targeted updates are allowed and assisted performance can be recorded honestly.
- Replace assert-based validation with explicit errors; add seven static-validator regression tests.
- Add research references and label scheduling/diagnostic limits as design heuristics.

No model-based behavioral benchmark or learning-effectiveness trial has been run.
